# node/ — Node.js wrapper (scaffold)

Planned layout:

- `autocipher.ts` — TS API surface (typed `Vault` ops).
- `dist/` — compiled output.
- The binding is generated by `native_ts` from the same `#[ac_fn]` definition
  set as the other wrappers.

Status: **scaffold only** — `native_ts` is a stub; the C contract in
`include/autocipher_capi.h` is authoritative.

Build: `cd node && npm install && npm run build`
